### 新增功能 / What's New

- **Makefile 构建系统与复杂规则解析**：自动检测工作区内的 `GNUmakefile`、`Makefile`、`makefile`；优先通过 GNU Make 数据库（`make -p -R -r -q`）解析动态生成的目标（`$(foreach)/$(eval)`、`$(wildcard ...)`、`ifeq`、多文件 `include`、`.PHONY`、`.DEFAULT_GOAL`）并合并 `##`/`#` 注释说明，`make` 不可用时自动退回静态解析器。
- **统一的运行配置体验**：自动发现的目标与手动新建的「Makefile 目标」统一归入同一分组、图标（`icons/makefile.svg`）、结构化编辑表单和启动流程，同时提供「运行 Makefile 目标」启动前任务（Before Launch）。
- **Make 工具链注册与设置页视图**：在 **构建、执行、部署 > 工具链 > 构建工具** 中注册 `Make` 工具链（支持 macOS Homebrew / CommandLineTools、Linux、Windows MSYS2 / Scoop 与 `PATH` 自动发现及项目/全局切换），并在 Makefile 设置页提供内联工具链选择器和查找顺序视图。
- **多平台打包**：提供 `darwin`（arm64 + x86_64 通用二进制）、`windows-x64`、`windows-arm64`、`linux-x64`、`linux-arm64` 五个平台归档。
